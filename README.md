# Tebak Lanjutan Ayat — Dark Premium 🌙

Game quiz Qur'an berbasis web, siap untuk GitHub Pages.

## Isi
- `index.html`
- `style.css`
- `script.js`
- `README.md`

## Fitur
- Dark premium UI
- 3 tingkat kesulitan
- 10 soal per permainan
- Timer 15 detik
- 3 nyawa
- Skor dan high score tersimpan di browser
- Feedback jawaban
- Audio pembacaan pilihan jawaban (opsional)
- Responsive untuk HP/laptop

## GitHub Pages
Upload semua file ke repository, lalu buka Settings → Pages dan pilih branch utama.

Catatan: verifikasi kembali teks ayat dengan mushaf/sumber Al-Qur'an tepercaya sebelum digunakan sebagai materi pembelajaran resmi.
